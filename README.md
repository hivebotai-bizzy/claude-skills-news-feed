# Claude Skills News Feed 🤖📰

Daily curated news about **Claude AI skills for small and medium businesses**.

Auto-generated by the HiveBot AI agent ecosystem. Updated every morning.

## Feed URL

```
https://raw.githubusercontent.com/hivebotai-bizzy/claude-skills-news-feed/main/feed.json
```

## Schema

See `feed.json` — entries are grouped by category:
- **news** — Anthropic releases, industry announcements, product updates
- **community** — Reddit discussions, Signal/WhatsApp community buzz, tutorials
- **vertical** — SMB vertical use cases (healthcare, legal, real estate, e-commerce, etc.)
- **job** — Job postings requiring Claude/prompt engineering skills

## Usage

```html
<script>
fetch('https://raw.githubusercontent.com/hivebotai-bizzy/claude-skills-news-feed/main/feed.json')
  .then(r => r.json())
  .then(feed => console.log(feed));
</script>
```
